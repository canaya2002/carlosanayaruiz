# ÍNDICE MAESTRO SEO — 100 ARTÍCULOS
## Parte 1: artículos 001–050
**Autor:** Carlos Anaya Ruiz
**Idioma objetivo:** Español (México / LATAM)
**Arquitectura:** 10 clústeres temáticos con pillar page + artículos satélite (topic cluster model)

---

## CÓMO USAR ESTE ÍNDICE

Cada entrada trae:
- **Título SEO** — optimizado para CTR, ≤60 caracteres visibles cuando es posible
- **Slug** — URL limpia, sin stopwords innecesarias
- **KW principal** — la keyword por la que se debe posicionar la URL (una sola, siempre)
- **KW secundarias** — variantes semánticas y long-tail para H2/H3 y cuerpo
- **Meta description** — ≤155 caracteres
- **Extensión objetivo** — palabras mínimas para competir en esa SERP

**Reglas globales de la arquitectura:**
1. Una keyword principal = una URL. Nunca dos artículos compitiendo por lo mismo (canibalización).
2. Cada artículo enlaza a la pillar de su clúster + 2 satélites hermanos + 1 cross-cluster.
3. Todo artículo lleva schema `Article` + `Person` (Carlos Anaya Ruiz) + `FAQPage` cuando tiene bloque de preguntas.
4. Bloque de respuesta directa en los primeros 120 caracteres del cuerpo → captura featured snippet y citación en LLMs.
